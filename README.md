# 🎟️ Plateforme de Billetterie France

Une plateforme moderne de vente de tickets pour les événements majeurs en France.

## 🌟 Événements Disponibles

- **🏉 Coupe du Monde de Rugby 2027** - L'événement majeur!
- ⚽ **Matchs de Football Ligue 1** - PSG vs Marseille et autres
- 🎵 **Festivals de Musique** - Glastonbury, festivals français
- 🎭 **Événements Culturels** - Festival d'Avignon
- 🏀 **Matchs de Basketball** - NBA All-Star Game

## 🛠️ Technologies

- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js + Express
- Base de données: MongoDB
- Authentification: JWT
- Paiements: Stripe

## 📦 Installation

```bash
npm install
npm start
```
